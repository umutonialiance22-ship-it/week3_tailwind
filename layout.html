This is intentionally a very long comment so that we can test how the media-object behaves when the content takes up a lot of horizontal and vertical space. The avatar should remain exactly the same size because the parent uses shrink-0. Instead of shrinking the avatar, the text simply wraps onto additional lines and continues naturally down the page. This is a very common pattern in real applications such as social media feeds, dashboards, forums, and comment systems.
